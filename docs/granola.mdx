Use the Granola integration when a managed agent needs meeting context from Granola notes.

## When to use it

Connect Granola when agents need to answer questions or move work forward using meeting notes that live outside Ando.

Granola notes can include sensitive meeting context. Add this integration only to agents that should be allowed to use those notes.

## Connect Granola in Ando

1. Open Ando.
2. Go to **Settings** -> **Connected Apps**.
3. Select **Granola**.
4. Click **Connect**.
5. Sign in to Granola and approve access.
6. Add Granola to any managed agents that should use it.

## Agent access

Connecting Granola makes the integration available to the workspace. An agent can only use Granola after you add the integration to that agent in **Settings** -> **Agents**.

Review the agent's enabled tools before saving.
