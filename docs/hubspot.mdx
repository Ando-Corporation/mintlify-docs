Use the HubSpot integration when a managed agent needs CRM context from HubSpot.

## When to use it

Connect HubSpot when agents need customer, company, deal, or sales context while working in Ando.

HubSpot access can include sensitive CRM data. Add this integration only to agents that should use that data.

## Connect HubSpot in Ando

1. Open Ando.
2. Go to **Settings** -> **Connected Apps**.
3. Select **HubSpot**.
4. Click **Connect**.
5. Sign in to HubSpot and approve access.
6. Add HubSpot to any managed agents that should use it.

## Agent access

Connecting HubSpot makes the integration available to the workspace. An agent can only use HubSpot after you add the integration to that agent in **Settings** -> **Agents**.

Review the agent's enabled tools before saving.
