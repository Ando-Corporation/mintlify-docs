Use the Sentry integration when a managed agent needs production error or release context from Sentry.

## When to use it

Connect Sentry when agents should help with incident response, bug triage, release follow-up, or debugging work.

Sentry access can include issue, trace, project, team, and release context. Add this integration only to agents that need operational access.

## Connect Sentry in Ando

1. Open Ando.
2. Go to **Settings** -> **Connected Apps**.
3. Select **Sentry**.
4. Click **Connect**.
5. Sign in to Sentry and approve access.
6. Add Sentry to any managed agents that should use it.

## Agent access

Connecting Sentry makes the integration available to the workspace. An agent can only use Sentry after you add the integration to that agent in **Settings** -> **Agents**.

Review the agent's enabled tools before saving. Give write-capable tools only to agents that should change Sentry data.
