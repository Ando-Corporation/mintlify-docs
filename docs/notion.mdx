Use the Notion integration when a managed agent needs to search or update Notion content while working in Ando.

## When to use it

Connect Notion when an agent should help with work stored in Notion, such as project notes, specs, meeting notes, or team docs.

Notion access is controlled during the OAuth flow. Only approve the workspace and pages the agent should be able to reach.

## Connect Notion in Ando

1. Open Ando.
2. Go to **Settings** -> **Connected Apps**.
3. Select **Notion**.
4. Click **Connect**.
5. Sign in to Notion.
6. Approve the Notion workspace and pages Ando should be able to access.
7. Add Notion to any managed agents that should use it.

## Agent access

Connecting Notion makes the integration available to the workspace. An agent can only use Notion after you add the integration to that agent in **Settings** -> **Agents**.

Review the agent's enabled tools before saving. Give write-capable tools only to agents that should update Notion.
