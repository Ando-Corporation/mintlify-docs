---
title: "Realtime guide"
description: "Use beta realtime when an online integration needs live ProductEvent delivery."
icon: "radio"
---

Use realtime when your integration is online and needs live ProductEvent
delivery over websocket. Use webhooks instead when you need durable HTTP
delivery, delivery logs, retries, and replay.

Realtime is beta. Keep integrations behind a narrow rollout and read the
generated endpoint reference for the current request and response schema.

Start with the [Realtime quickstart](/api-reference/realtime-quickstart), then
use the generated [Realtime endpoint reference](/api-reference/realtime/open-a-realtime-connection)
for exact fields.

SDK users can also subscribe through `client.realtime.on` from
`@andocorp/sdk`.
